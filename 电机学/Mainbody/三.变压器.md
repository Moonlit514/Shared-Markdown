# 1.基本结构（了解）
## （1）<span style="color:red">额定值</span>
铭牌上标注的额定值，==三相的一定是线值== ，<span style="color:red">线值是人为规定的</span>
- 额定电压 $U_{1N} / U_{2N}$
   $U_{2N}$指==二次空载额定电压==,即当$U_1 = U_{1N}$ 时, $\boxed{U_{20 } = U_{2N}}$
- 额定电流$I_{1N} / I_{2N}$
  满载电流值，即长期工作所允许的最大电流
- 额定容量 $S_N$ ==(视在功率)==
  单相变压器：$S_N=U_{1N}I_{1N}=U_{2N}I_{2N}$          （==理想变压器的能量守恒==）
  三相变压器：$S_N=\sqrt{3} U_{1N}I_{1N}=\sqrt{3} U_{2N}I_{2N}$ （==理想变压器的能量守恒==）
- 额定频率 $f_N$ : 一般：$f_N=50Hz$（工频）

# 2.运行特性
规定正方向：==右手定则==

主磁通 $\Phi$ 和漏磁通 $\Phi_{1\sigma}$ 的区别（[[一. 绪论]] 核心磁路公式）

- 所经磁路的磁阻不同
  $\boxed{R_m = \frac{l}{\mu S}}$ ，主磁通沿铁心闭合，$\mu$为==非常数==，存在==饱和现象==
             漏磁通主要沿非铁磁材料(油、空气)闭合，$\mu$为==常数==
- 所起的作用不同
  主磁通传递能量，漏磁通不传递能量
- 大小不同
  主磁通占总磁通的绝大部分

# 3.物理过程与方程
### （1）变比：匝数只和每一相的线圈有关，==变比一定是相电压之比==
$$\boxed{k = \frac{E_1}{E_2} = \frac{N_1}{N_2} \approx \frac{U_{1\phi}}{U_{2\phi}}}$$
### （2)<span style="color:red">电势E与主磁通Φm的关系</span>
$\phi_m = \Phi_m \sin\omega t \\[8pt]$
$e_1 = -N_1 \frac{d\phi_m}{dt} = N_1 \Phi_m \omega \sin\left(\omega t - \frac{\pi}{2}\right) = \sqrt{2} E_1 \sin\left(\omega t - \frac{\pi}{2}\right)  \\[8pt]$
$e_2 = -N_2 \frac{d\phi_m}{dt} = N_2 \Phi_m \omega \sin\left(\omega t - \frac{\pi}{2}\right) = \sqrt{2} E_2 \sin\left(\omega t - \frac{\pi}{2}\right)  \\[8pt]$
$E_1 = \frac{1}{\sqrt{2}} \times 2\pi f \times N_1 \Phi_m \approx \boxed{ 4.44 f N_1 \Phi_m}\\[8pt]$
$E_2 = \frac{1}{\sqrt{2}} \times 2\pi f \times N_2 \Phi_m \approx \boxed{ 4.44 f N_2 \Phi_m}\\[8pt]$
[[相位分析]]  电势滞后磁通90°
推出：$$\boxed{\Phi_m \approx \frac{U_1}{4.44fN_1}}$$
说明：<span style="color:red">影响主磁通大小的因素是电源电压U1、电源频率f和一次侧线圈匝数N1，</span>
      与铁心材质及几何尺寸基本无关

### （3）<span style="color:red">电流分析</span>
电网电压是标准正弦波，由$e_1 = -N_1 \frac{d\phi_m}{dt}$ ,主磁通也是正弦波，铁磁材料的非饱和性，$\Phi=BS$ 且 $Hl=NI$ ,所以主磁通和励磁电流也是这种曲线

# 4.等效电路
- 励磁阻抗 ：$Z_m=R_m+jX_m$  （==变量==，铁磁材料的不饱和性）
  <span style="color:red">（这里的Rm是励磁电阻，注意和磁阻区分）</span>
  $R_m$ ：励磁电阻 ，对应==铁耗==的等效电阻（==铁耗是有功功率==）
  $X_m$ ：励磁电抗，​$\boxed{X_m=\omega L_m=\omega \frac{N^2}{R_m}=\omega \frac{\mu S N^2}{l}}$ ,是用来建立磁场的（==无功，对应励磁电流==）

    - 1. 励磁电压升高rm和Xm
    $\boxed{U_1 \approx E_1 = 4.44 f N_1 \Phi_m}$，主磁通增大，进入磁饱和区，磁导率急剧下降$$P_{\text{Fe}} \propto f^{1.3} B_m^2$$铁耗增加，但增加幅度远小于励磁电流I0的增幅，$$r_m = \frac{P_{Fe}} {I_0^2}$$因此==rm减小==$$\boxed{R_m = \frac{l}{\mu S}}$$
    因此Rm增大，==Xm减小==
    
    - 2. 在变压器接入电网电压几乎额定的情况下，可以认为<span style="color:red">Zm恒定</span>（分析同上）

- 漏电抗 ：$X_σ​=ωLσ​$ （==常量==，因为漏磁路的磁阻是固定的）$$E_{1\sigma} \propto \Phi_{1 \sigma} \propto I_m$$              <span style="color:red">漏磁通和产生它的电流是正比例关系(磁阻恒定)</span>

# 5.标幺值  $\boxed{标幺值=\frac{实际值}{基值}}$

电压、电流、阻抗、功率等通常不用实际值表示，
而用其实际值与某一选定的选定值（基值）之比来表示
此选定值称为基值，此比值为该物理量的标幺值或相对值
一般取==额定值==作为基值

# 7.二次侧端电压和电流关系
![[变压器运行特性曲线.png]]==上升一定容性，容性不一定上升==
==感性负载一定下降，功率因数越低，下降幅度越大==

- 电压调整率$$\boxed{\begin{align*} \Delta u &= I^{*}\left(r_{k}^{*} \cos \varphi_{2}+x_{k}^{*} \sin \varphi_{2}\right) \times 100\% \\ &= \beta\left(r_{k}^{*} \cos \varphi_{2}+x_{k}^{*} \sin \varphi_{2}\right) \times 100\% \end{align*}}$$
  其中$I^*$是负载电流的标幺值，$I^{*}=\frac {I_2}{​I_{2N}}​​=\frac{​{I_2}^′}{I_{1N}}​​=I_2^∗​=I^∗$
  $\beta$ 为负载系数，与$I^{*}$相等，即实际负载电流与额定电流的比值
  $r_k^*，x_k^*$ 是短路参数，是漏磁阻抗来的，可以认为是==常数==
  $\varphi_{2}$ 是负载功率因数角

# 8.功率关系
- 铜耗和铁耗
  因为变压器接在电网中，U1和f一般都是固定的，所以==铁耗为不变损耗==，
  等于空载损耗$$P_{Fe}=p_0$$
  铜耗则和电流有关，所以==铜耗是可变损耗==，
                 其中pkN为额定电流时的铜耗（短路损耗）
                 $$p_{Cu}=\beta^2 p_{kN}$$
                 
<span style="color:red">结论：不变损耗=可变损耗时，效率达最大值，一般变压器不是长期额定负载下运行，负载系数在0.5-0.6之间

>[!note] Thm 1
>同余式$f(x)=a_{n}x^n+a_{a-1}+\cdots+a_{0} \equiv 0 \pmod{p}$与一个次数不超过$p-1$的素数模$p$的同余式等价.
>这个命题等价于$x^p \equiv x \pmod{p}$

由费马小定理立得.

>[!note] Lemma
>同余式$a_{n}x^n+a_{a-1}+\cdots+a_{0} \equiv 0 \pmod{p}$解的个数不超过其次数.

>[!proof]
>设解数超过$n$个，即至少有$n+1$个解，设为$x \equiv \alpha_{i} \pmod{p},i=1,2,..,n+1$
>则$$f(x) \equiv a_{n}(x-\alpha_{1})(x-\alpha_{2})\cdots(x-\alpha_{n}) \pmod{p}$$
>由于$f(\alpha_{n+1}) \equiv 0 \pmod{p}$，从而
>$$a_n (\alpha_{n+1} - \alpha_1)(\alpha_{n+1} - \alpha_2)\cdots(\alpha_{n+1} - \alpha_n) \equiv 0 \pmod{p}$$
>由于$p$为素数，从而$a_{n}\not\equiv 0 \pmod{p}$，从而必有一$a_{i}$使得$\alpha_{n+1}-\alpha_{i} \equiv 0 \pmod{p}$，与假设矛盾.

由引理
>[!note] Thm 2
>设$p$为素数
>$$x^{p-1}-1 \equiv (x-1)(x-2)\cdots (x-(p-1)) \pmod{p}$$

>[!proof]+
>由欧拉定理立得$1,2,\dots,p-1$为方程$x^{p-1}-1 \equiv 0 \pmod{p}$的$p-1$个解.
>由引理，
>方程$x^{p-1}-1 \equiv 0 \pmod{p}$最多只有$p-1$个解.
>Thm 2是易得的。

>[!note] Thm 3 威尔逊定理
>设$p$为素数
>$$(p-1)!+1 \equiv 0 \pmod{p}$$

考虑模$p$下的乘法群$\mathbb{Z}_{p}^*$，除了$1$和$p-1$(即$-1$)之外，群中每个元素都有唯一的乘法逆元.($1$和$p-1$自己是自己的乘法逆元)
这是由于$a \in {1,2,\dots,p-1}$，$(a,p)=1$，从而$ax+py=1$，即$ax \equiv 1 \pmod{p}$，并且可以证明这个逆元是唯一的.
证明思路：将 $(p−1)!=1⋅2⋅⋯⋅(p−1)$ 中的因子重新配对，使每个因子与其逆元相乘.

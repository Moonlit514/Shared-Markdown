>[!example] Exa 1
>解同余式
>$$f(x)=x^4+2x^3+8x+9 \equiv 0 \pmod{35}$$

求解思路：
原同余式与同余式组$f(x) \equiv 0 \pmod{5},f(x) \equiv 0 \pmod{7}$
此后把$0,1,2,3,4$与$0,1,2,3,4,5,6,7$分别代入验证即可.

为了讨论更一般的情况，研究
$$f(x)\equiv 0 \pmod{p^\alpha}$$

>[!note] Thm 1 霍纳法则 (Horner's Method)
>设$x \equiv x_{1} \pmod{p}$是$f(x)\equiv 0 \pmod{p}$的一解，且$p \nmid f'(x)$则$f(x)\equiv 0 \pmod{p^\alpha}$的一解为
>$$x \equiv x_{\alpha} \pmod{p^\alpha},\quad 其中x_{a}\equiv x_{1}\pmod{p}$$
>

>[!proof]+
>现要求满足$f(x_{1}+pt_{1}) \equiv 0 \pmod{p^2}$的$t_{1}$.
>应用$Taylor$公式，左端展开得$f(x_{1})+pt_{1}f'(x_{1}) \equiv 0 \pmod{p^2}$，由于$f(x_{1}) \equiv 0 \pmod{p}$，得到
>$$t_{1}f'(x_{1})\equiv -\displaystyle\frac{f(x_{1})}{p} \pmod{p}$$
>由于$p \nmid f'(x_{1})$(回顾一次同余式解的个数)，从而恰有唯一解$t_{1} \equiv t_{1}'\pmod{p}$，即$t_{1}=t_{1}'+pt_{2}$
>从而$x=x_{1}+p(t_{1}'+pt_{2})=x_{2}+p^2t_{2}$. 故$x \equiv x_{2} \pmod{p^2}$是$f(x) \equiv 0 \pmod{p^2}$的一解.
>由数学归纳法，后续同理证明(省略).

>[!example] Exa 2
>解同余式$x^4+7x+4 \equiv 0 \pmod{27}$.

求解思路：
$f(x) \equiv 0 \pmod{3}$有一解$x \equiv 1 \pmod{3}$，且$f'(1) \not\equiv 0 \pmod{3}$
设$x=1+3t_{1}$，代入$f(x) \equiv 0 \pmod{9}$，再用泰勒公式展开，之后的操作与上述证明过程是类似的。

## 代码框架

了解了编译顺序，我们就对我们写的代码进行分类：
先是 __Start__ 文件里的启动文件；然后是 __Library__ 中单片机要用到的各种外设的库函数的.h/.c文件；接着是 __System__ 里最基础的一些复用代码以及时钟等的基础配置；往上则是 __Hardware__ 中直接基于头文件写的控制外设的代码，以及最后再 __User__ 中的顶层调用。所以你可以发现， __main__ 里面的代码是非常简单的。（那么，代价呢）

## GPIO输入输出

GPIO（General Purpose Input Output）即通用输入输出，是一种最基础的输入输出接口，它有八种模式，分别是：你先别管
我们目前先知道它可以输入和输出，然后再细分以及复用。
我们先看一下GPIO的基本架构：

<img src="..\img\GPIOBasic.png",alt = "GPIOBasic.png"，zoom=100%>

我们之前说过，GPIO是挂在APB2总线上的，而这会影响我们之后的操作。
GPIO是通过寄存器控制的，而驱动器是为了增加信号的驱动能力的，毕竟你不能指望小寄存器去点灯。

进入正题：输入和输出

<img src="..\img\IO.png",alt = "IO.png"，zoom=100%>

### GPIO输出

看上图的下半部分，即输出模式：
它有一个CMOS控制，根据一点简单的MOSFET小知识，我们可以对它进行如下两种操作：

- 一开一关：可以输出高电平或者低电平，这就是我们最常用的推挽输出模式，驱动力强，且只听单片机的。
- p关n开：即开漏输出，这个模式下GPIO本身不输出，但可以通过外界上拉控制高于3.3v的信号。
加上复用两种就是四种输出模式。

### GPIO输入

看上图的上半部分，即输入模式：
首先是选择模式的开关，上拉或者下拉或者不拉（浮空），这决定默认状态是高还是低；然后输入信号会经过一个施密特触发器（*图片有误*），
这个玩意的作用是用于整形，设置阈值，高于某值为1，低于某值为0。
此外还有一个特殊的，直接输入模拟信号。

## 代码部分

接下来是如何实际去写GPIO的代码。其中很多操作是在配置其它外设是通用的，所以会重点讲讲相同的，以后便默认大家都知道。
由于我给的示例文件中并没有使用这一功能，所以请看 __GPIO_Example__ 文件夹。
首先我们知道GPIO是挂在APB2总线上的，所以我们需要先打开APB2总线的时钟。

```c
/*开启时钟*/
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);//开启GPIOA的时钟
//使用各个外设前必须开启时钟，否则对外设的操作无效

```

要注意的是记得打开时钟，因为单片机为了省电，各种你以为上电就开的东西是关着的。

然后是初始化配置GPIO。库函数将GPIO的配置封装成了结构体，我们只需要调用并配置即可。

```c
/*GPIO初始化*/
GPIO_InitTypeDef GPIO_InitStructure;//定义结构体变量

GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;//GPIO模式，赋值为推挽输出模式
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;//GPIO引脚，赋值为第0号引脚
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;//GPIO速度，赋值为50MHz

GPIO_Init(GPIOA, &GPIO_InitStructure);//将赋值后的构体变量传递给GPIO_Init函数
                                    //函数内部会自动根据结构体的参数配置相应寄存器
                                    //实现GPIOA的初始化
```

最后是写入输出的方法：

```c
    /*方法1：GPIO_ResetBits设置低电平，GPIO_SetBits设置高电平*/
    GPIO_ResetBits(GPIOA, GPIO_Pin_0);//将PA0引脚设置为低电平
    Delay_ms(500);
    GPIO_SetBits(GPIOA, GPIO_Pin_0);//将PA0引脚设置为高电平
    Delay_ms(500);
    
    /*方法2：GPIO_WriteBit设置低/高电平，由Bit_RESET/Bit_SET指定*/
    GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);//将PA0引脚设置为低电平
    Delay_ms(500);
    GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);//将PA0引脚设置为高电平
    Delay_ms(500);
    
    /*方法3：GPIO_WriteBit设置低/高电平，由数据0/1指定，数据需要强转为BitAction类型*/
    GPIO_WriteBit(GPIOA, GPIO_Pin_0, (BitAction)0);//将PA0引脚设置为低电平
    Delay_ms(500);
    GPIO_WriteBit(GPIOA, GPIO_Pin_0, (BitAction)1);//将PA0引脚设置为高电平
    Delay_ms(500);
```
